# Converge_figs() pulls convergence figures for each parameter

The convergence summary plots generated by
[`runjags::run.jags()`](https://rdrr.io/pkg/runjags/man/run.jags.html)
for the defining parameters of the selected distribution

## Usage

``` r
converge_figs(distribution, jags_model_run)
```

## Arguments

- distribution:

  One of `'Normal'`, `'Skewed'`, `'Lognormal'`, `'Gamma'`, or `'Beta'`.

- jags_model_run:

  The output list returned from
  [`run_likelihood()`](https://luddaludwig.github.io/UPLforOAR/reference/run_likelihood.md),
  which includes the jags model `run_results`, likelihood distribution
  type, `data`, `xvals`, and `future_tests` that were used as inputs to
  [`run_likelihood()`](https://luddaludwig.github.io/UPLforOAR/reference/run_likelihood.md)

## Value

A list of histograms and MCMC chain plots per parameter
